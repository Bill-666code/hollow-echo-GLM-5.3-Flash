# 空洞余响 · Hollow Echo

一个致敬《空洞骑士》的横版动作游戏。纯 HTML5 Canvas + 原生 JavaScript，全部画面程序化绘制、音效 WebAudio 实时合成，无任何外部素材。

## 项目提示词

> 生成一个空洞骑士类横版动作游戏：角色使用剑攻击，支持二段跳和冲刺闪避，探索相互连通的区域，击败Boss获得新能力，有血量显示。游戏玩法和游戏的画面效果尽量贴近空洞骑士。

## 运行

```bash
cd hollow-echo
python3 -m http.server 8123
# 浏览器打开 http://localhost:8123
```

（直接双击 index.html 也可以运行。）

## 操作

| 动作 | 按键 |
| --- | --- |
| 移动 | ← → / A D |
| 跳跃 / 二段跳 | Z / K / 空格 |
| 攻击（↑↓ 改变劈砍方向） | X / J |
| 冲刺闪避 | C / L / Shift |
| 下劈弹跳（Pogo） | 空中 ↓ + 攻击命中敌人 / 尖刺 / 弹幕 |
| 聚魂疗伤 | 长按 V / H（消耗 33 灵魂） |
| 灵魂弹（击败 Boss 1 后） | F |
| 重斩（击败 Boss 2 后） | 长按攻击 ≥0.35s 后松开 |
| 休息（存复活点 + 回满血） | 站上长椅按 ↓ |
| 地图 / 暂停 / 静音 | M / Esc / N |

## 玩法

- **互相连通的 6 个区域**：苍白之径 → 十字路口（长椅枢纽）→ 真菌洞窟 / 沉眠深渊 → 守卫之厅 / 深渊王座，击败守卫后 opens 新捷径，形成环路。
- **两个 Boss**：
  - **残破守卫**（挥锤 / 跃顶重压 / 冲锋撞墙眩晕，半血狂暴 + 天降碎石）→ 掉落 **魂之利刃**
  - **深渊骑士**（瞬移连斩 / 冲刺突刺 / 灵魂弹幕，半血狂暴）→ 掉落 **大地斩**
- **灵魂机制**：攻击敌人积攒灵魂，长按聚魂回血，或释放灵魂弹。
- **血量 / 灵魂 / 吉欧**：左上面具即血量，圆形容器即灵魂，右上吉欧计数；死亡后在最后休息的长椅复活，敌人重生（Boss 不复活）。

## 技术

- Canvas 2D，960×540 逻辑分辨率自适应缩放；瓦片层与远景视差层按房间预渲染离屏画布。
- 物理：土狼时间、跳跃缓冲、可变跳高、单向平台、下落穿层、命中停顿（hitstop）、屏幕震动、慢动作。
- 全程序化美术：小骑士、三种敌人、两个 Boss、苔草 / 发光蘑菇 / 水晶 / 雾气 / 黑暗光照均为代码绘制。
- WebAudio 合成全部音效与环境低鸣。
- 调试钩子：控制台 `__game.state() / __game.step(n) / __game.teleport(x,y,room)` 等。
